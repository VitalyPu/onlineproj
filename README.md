# onlineproj

Тестовый проект для проверки связки облачной среды разработки (Claude Code) с GitHub-репозиторием.

## Назначение

- Проверить, что репозиторий доступен для чтения и записи из сессии Claude Code.
- Убедиться, что коммиты и пуш в ветку работают.
- Служить пустой «песочницей» для экспериментов и учебных задач.

## Статус

Проект находится на начальной стадии: исходного кода пока нет, только этот README.

## Структура

```
onlineproj/
└── README.md   # описание проекта
```

## Как начать работу

```bash
git clone https://github.com/VitalyPu/onlineproj.git
cd onlineproj
```

## Рабочий процесс

1. Создать ветку для изменений.
2. Внести правки и закоммитить их.
3. Отправить ветку в `origin` (`git push -u origin <ветка>`).
4. При необходимости открыть Pull Request.
